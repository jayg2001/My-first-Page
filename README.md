# Hello World Project

## Description
This is my first HTML project. It displays the message "Hello World!" in a web browser.

## Files
- index.html – Main HTML file
- README.md – Project documentation

## How to Run
1. Download or clone this project.
2. Open the project folder.
3. Double-click the `index.html` file.

OR

Right-click on `index.html` and choose **Open with** → your web browser (Chrome, Edge, Firefox, etc.).

The browser will display:

Hello World!
